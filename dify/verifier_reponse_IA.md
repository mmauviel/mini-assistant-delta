# Vérifier la réponse de l'IA (étape 4)

Garder à côté : la fiche (étape 1) et le prompt (étape 2). Cocher chaque point.

## Les chiffres
- [ ] Chaque chiffre de la réponse se retrouve dans le prompt (utiliser la liste (a) de l'autocontrôle, et Ctrl+F dans le prompt).
- [ ] Chaque calcul montré est juste (refaire les soustractions à la calculatrice).
- [ ] Aucun chiffre nouveau sans calcul montré.

## L'interprétation (règles du prompt)
- [ ] Le niveau de perturbation est le même que dans le prompt (récurrente / à risque / ponctuelle).
- [ ] « Contrôlable / externe / mixte » : toute la fourchette au-dessus de 50 % = contrôlable, toute en dessous = externe, sinon mixte.
- [ ] Météo : « plus de la moitié » seulement si la part de mauvais temps dépasse 50 %.
- [ ] Si les retards sont surtout externes, aucune solution interne (équipages, maintenance) n'est proposée.
- [ ] Les 2 suggestions sont étiquetées « Suggestion » et citent un chiffre.

## Les inventions (erreurs vues dans l'annexe D)
- [ ] Pas de statut d'aéroport (hub, focus city), pas de nom d'équipe ou de programme.
- [ ] Pas d'explication absente des données (saison, vacances, « météo d'été »…).
- [ ] Pas de « nous avons vérifié » sans calcul montré.

## Le message aux passagers
- [ ] 3 phrases, ton soutenu, sans statistiques.
- [ ] Aucune promesse sur ce que fait Delta ; seulement des faits et ce que le passager peut faire (application Fly Delta).

## L'autocontrôle
- [ ] La liste (b) signale bien les suggestions comme non tirées des données. Une réponse « None » est suspecte : relire encore plus attentivement.

Si un point n'est pas coché : corriger la phrase à la main (ou demander à l'IA de la corriger), puis revérifier ce point.
