# Check the AI's answer (step 4)

Keep the briefing (step 1) and the prompt (step 2) next to you. Tick each point.

## Numbers
- [ ] Every number in the answer appears in the prompt (use list (a) of the self-check, and Ctrl+F in the prompt).
- [ ] Every calculation shown is right (redo the subtractions on a calculator).
- [ ] No new number without a calculation shown.

## Interpretation (prompt rules)
- [ ] The disruption level is the same as in the prompt (recurring / at risk / one-off).
- [ ] Controllable / external / mixed: whole range above 50% = mostly controllable, whole range below = mostly external, otherwise mixed.
- [ ] Weather: "more than half" only if the bad-weather share is above 50%.
- [ ] If delays are mostly external, no internal fix (crews, maintenance) is suggested.
- [ ] Both suggestions are labelled "Suggestion" and cite a number.

## Inventions (errors seen in appendix D)
- [ ] No airport status (hub, focus city), no team or programme names.
- [ ] No explanation missing from the data (season, holidays, "summer weather"…).
- [ ] No "we checked" without a calculation shown.

## Passenger message
- [ ] 3 sentences, formal tone, no statistics.
- [ ] No promise about what Delta is doing; only facts and what the passenger can do (Fly Delta app).

## Self-check
- [ ] List (b) flags the suggestions as not taken from the data. An answer of "None" is suspicious: read even more carefully.

If a point is not ticked: correct the sentence by hand (or ask the AI to correct it), then check that point again.
